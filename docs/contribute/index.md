# Contribute

STUF is an early-stage open-source project. Contributions, technical review, and implementation feedback are welcome.

## How to contribute

Useful contributions include:

- code review
- documentation improvements
- tests and examples
- threat-model feedback
- embedded implementation feedback
- protocol adapters and integrations
- bug reports and feature proposals

The main repository is:

[github.com/juneswift/stuf](https://github.com/juneswift/stuf)

For code changes, open an issue or pull request in the repository.

## Get in touch

For technical questions, collaboration, pilot implementations, or security-review interest, open an issue in the repository or contact Juneswift through the project repository.

STUF is not production-ready and has not yet undergone independent security review.
